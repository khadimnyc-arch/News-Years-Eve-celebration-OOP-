# Times Square New Year's Eve (OOP Perspective Visualizer)

An object-oriented Processing application written in Java that simulates a detailed Times Square New Year's Eve scene with dynamic confetti animations.

## Features

* **3D Perspective Scene:** Renders angled side buildings, vibrant Broadway billboards, and the main center ball drop tower.
* **Object-Oriented Confetti (`Confetti.java`):** Manages individual confetti particle properties (position, size, RGB color) and simulates randomized falling physics.

## How to Run

1. Clone or download this repository.
2. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
4. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
